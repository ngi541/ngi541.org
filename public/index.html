REFERENCE INTEGRATION

NGINX HTTP/3

NGI541 can be integrated into an existing NGINX HTTP/3 stack without replacing OpenSSL.

OpenSSL continues to handle TLS 1.3, certificates and key derivation, while NGI541 executes selected AES packet-protection operations through its public prepared-key API.

The integration is applied as a patch to a pinned NGINX source tree and keeps the surrounding TLS architecture unchanged.

$ git clone https://github.com/ngi541/ngi541-nginx.git
